# Baykuş Lig Windows installer temeli

## 8 Ekim — yeni kurulum API'si ve yerel imzalı VM teslimi

Güncel native akış `WindowsServiceClient.installation_context` → `check_installation` → `prepare_with_progress` → `begin` → `authorize_installation` → `commit` olarak bağlandı. İlk imzalı servis bootstrap'ı kalkandaki UAC worker'ında yapılır; UI ve online client normal kullanıcıda kalır. Gerçek callback'ler iki bara/durum metnine taşınır; yalnız `Completed` / doğrulanmış `NoOp` başarıdır. Launcher, kullanıcı state/pencerelerinden önce `application_guard` alır ve yaşam boyu tutar. Çalışan uygulama bütün oturumlarda kullanıcı tarafından kapatılmalıdır; otomatik zorla kapatma yoktur.

[VM test installer'ı](./dist/VM_2026.10.08/BaykusLig_VM_0.1.0.exe), [hazırlık](./dist/VM_2026.10.08/README.md), [kullanıcının uygulayacağı yayın adımları](./dist/VM_2026.10.08/YAYINLA.md). Ayrı test sertifikasıyla imzalı launcher, NSIS, helper ve offline politika hazırlandı. Metadata/updater paket imzası doğrulandı; host üzerinde yalnız gizli, salt okunur `--inspect` çalıştırıldı. **Yayımlama kullanıcıya bırakıldı:** R2/katalog/server config/Docker/host trust store değiştirilmedi; VM'de gerçek kurulum yapılmadı. Yeni test public anahtarları yayın öncesinde sunucuya tanıtılmalı.

VM build'i `local-test-tls` özelliği ve derleme sırasında `BAYKUS_INSTALLER_TRUST`, `BAYKUS_INSTALLER_HELPER`, `BAYKUS_INSTALLER_CA` dosyalarıyla üretilir. Helper public kökleri `UPDATE_SERVICE_BOOTSTRAP_KEYS`; launcher policy'si `BAYKUS_DESKTOP_POLICY` ile sabitlenir. Varsayılan `trust.json` hâlâ dağıtım yapılandırması şablonudur; VM anahtarları varsayılan/üretim trust yapılmadı. Private dosyalar Git ignored `.local-release/vm-20261008/private/` altında, teslimin dışındadır.

Windows adaptörünün mevcut tek ürün klasörü sözleşmesi nedeniyle bu test paketi `C:\Program Files\BaykusLig` hedefine kurar. Tüm ayrıntılar ve açık kabul [entegrasyon doğrulama kaydında](../../docs/planlama/dogrulama/windows-installer-api-entegrasyonu.md). Aşağıdaki eski `check/prepare` bağlantısı ve demo EXE kayıtları tarihsel sürümlerdir.

## 8 Ekim — mevcut update-client entegrasyonu (kaynak)

Installer `updates/crates/update-client` paketini path dependency olarak kullanır; update crate kaynakları değiştirilmedi. `startup_check`, `update_status`, `prepare_update` native komutları eklendi. Açılışta mevcut Windows/mimari/WebView2/registry önkontrolü tamamlanana kadar kalkan devre dışıdır; otomatik UAC yoktur. Kaynak yapılandırılmış ve native kurulum bağlamı bulunmuşsa mevcut `check()` kullanılır. Onay/sürükleme sonrası mevcut `prepare()` tam paketi indirir, hash/boyut ve paket imzasını doğrular. İşlem kimliği native üretilir; eski kimlik reddedilir, paket yolu ve trust alanları UI girdisi değildir.

`trust.json` derleme sırasında gömülen yapılandırma şablonudur: server origin, channel, metadata public key'leri, paket public key'i ve izinli storage hostları gerekir. Private key veya admin/upload tokenı içermez. Origin şu an `null`; gerçek yayın kaynağı hazır varsayılmaz. Kurulu bağlam için sabit Program Files EXE'si ve beklenen perMachine registry kaydındaki DisplayVersion/InstallLocation/InstallationId ipuçları kullanılır; registry verileri kurulum veya publisher kanıtı değildir. İlk kurulum ve kalıcı ürün bağlamı adaptörü beklenir, sahte 0.0.0/installation identity üretilmez.

Mevcut API ara byte/kurulum callback'i sağlamaz. Hazırlama boyunca belirsiz ilerleme ve "indiriliyor ve doğrulanıyor", başarıda yalnız "Paket hazır" gösterilir. Sağ bar doldurulmaz; kurulum tamamlandı veya dosyalar sağlam denmez. Normal native giriş artık 3+1+3 saniyelik demo çalıştırmaz; yalnız açık `data-preview-progress="true"` önizlemesi ve tarayıcı/test modu demo kullanır. Somut Windows NSIS/servis adaptörü olmadığı için `install()` bağlanmadı; Program Files, kayıt veya servis mutasyonu yapılmaz. Kontrollerin disk/dependency/hedef kullanılabilirliği ve ortak bekleyen işlem bölümleri henüz mevcut crate ile sağlanamaz.

İlk kurulum, onarım, korumalı staging/dosya ağacı doğrulaması, gerçek yüzde bildirimi, ortak kilit/journal, sonuç doğrulaması ve ürün bağlamı için [update-client sahibine talepler](../../docs/planlama/update-client-installer-talepleri.md) kaydedildi.
